# v1.4.3 reciprocal CRJ700 exchange candidates

The existing 1,286-flight draft is preserved. Reciprocal roundtrip pairs sharing the same home airport can sometimes exchange aircraft-days while preserving aircraft endpoints. Candidate matches identified from flight-by-flight windows include R338 PHF–SYR with R346 PHF–DAY; R338 PHF–PVD with R308 PHF–CHS, R314 PHF–BNA, R334 PHF–MSY, or R346 PHF–BWI; and R339 PHF–CHS with R334 PHF–PVD. These are feasibility leads only, not native-validated exchanges. Trading a longer turn for a shorter one moves flying between aircraft-days without necessarily improving fleet-wide utilization. Before adopting any, independently check complete line continuity, minimum turns, banks, fixed gate/stand inventory, and the >8 passengers/day one-stop protection in both itinerary models. The previously constructed 1,292-flight candidate remains separate and unpublished.
